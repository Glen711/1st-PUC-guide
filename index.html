Quick Recall

Important formulas and identities for last-minute revision.

🚀 Projectile Motion

tₘ = v₀ sinθ / g
T = 2v₀ sinθ / g
H = v₀² sin²θ / 2g
R = v₀² sin2θ / g

⚙️ Atwood Machine

a = (m₂ − m₁)g / (m₁ + m₂)
T = 2m₁m₂g / (m₁ + m₂)

Memory: Difference / Sum.

⚡ Work & Energy

W = ΔK
F = −dV/dx
V = ½kx²

⚛️ Chemical Bonding

FC = V − N − B/2
BO = ½(Nᵦ − Nₐ)

🔬 Bohr Model

rₙ = 52.9n²/Z pm
Eₙ = −2.18×10⁻¹⁸ Z²/n² J
λ = h/mv

🧮 Permutations

ⁿPᵣ = n!/(n−r)!
ⁿPᵣ = ⁿCᵣ × r!
ⁿCᵣ = n!/[r!(n−r)!]

🧮 Binomial

(a+b)ⁿ = Σ ⁿCᵣ aⁿ⁻ʳbʳ
Terms = n+1
Σ ⁿCᵣ = 2ⁿ

📏 Straight Lines

m = (y₂−y₁)/(x₂−x₁)
y−y₀ = m(x−x₀)
d = |Ax₁+By₁+C|/√(A²+B²)

📐 Set Laws

(A∪B)' = A'∩B'
(A∩B)' = A'∪B'
A∩(B∪C) = (A∩B)∪(A∩C)

⚠️ Inequalities

× or ÷ positive → SAME sign
× or ÷ negative → REVERSE sign

Number line: Open circle for < / >, filled circle for ≤ / ≥.
