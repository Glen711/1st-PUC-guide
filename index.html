🔢 Mathematics — P&C

🟣 Trigonometry — Fundamentals

📐 Trigonometry — Compound

cos(x+y)=cosxcosy−sinxsiny

🔁 Trigonometry — Transformations

cosx+cosy=2cos[(x+y)/2]cos[(x−y)/2]

ℂ Complex Numbers

➗ Complex Inverse

Exam Booster

A final revision system for accuracy, recall and confident exam writing.

📝 Physics — Derivation Writing

  1. Write the starting principle clearly.
  2. Define directions and components before substituting.
  3. Show every important algebraic transition.
  4. Box the final expression and state the conclusion.

⚛️ Chemistry — Formula Accuracy

  1. For formal charge, remember Free − Lone − Half Shared.
  2. For bond order, subtract antibonding electrons.
  3. For Bohr radius, remember n²/Z.
  4. For Bohr energy, remember −Z²/n².
  5. For complex-number relations, remember i²=−1.

🧮 Mathematics — P&C and Binomial

  1. Ask whether order matters before using P or C.
  2. Repeated objects require repeated-group factorials in the denominator.
  3. For binomial expansion, a power goes down and b power goes up.
  4. For coefficient sum, put both variables equal to 1.

📐 Mathematics — Trigonometry

  1. Memorize SC+CS for sin(A+B).
  2. Memorize CC−SS for cos(A+B).
  3. For 3x, start with 2x+x.
  4. For sum-to-product, remember the half-sum and half-difference.

📏 Mathematics — Straight Lines

  1. Slope = RISE/RUN.
  2. Parallel lines have the same slope.
  3. Perpendicular slopes multiply to −1.
  4. Distance formulas need an absolute value.

ℂ Mathematics — Complex Numbers

  1. Remember the i cycle of 4.
  2. Conjugate changes only the sign of the imaginary term.
  3. For inverse, multiply by the conjugate.
  4. Modulus is always non-negative.
